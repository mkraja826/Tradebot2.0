# Chart execution overlays
Read-only position levels now use distinct entry solid / mark dotted / SL and TP dashed lines. Compact fill symbols distinguish entry, exit, reversal, increase, reduction and other fill, with action filters. Expand Chart executions to inspect recorded timestamp, direction, contracts and actual fill price; select a fill to pan to its observed candle and draw a labeled horizontal exact-price line. No marker is claimed to be at actual price, and unmatched or still-open candle intervals are explicitly marked outside loaded completed candles. List shows most recent 100 matching fills; count compares matching fills in window to all recorded fills. Focus scale can clip price lines; raw prices remain in list. Current position lines remain gated by existing observation freshness and matching bracket evidence. All changes display-only; no execution or strategy modification. Browser fixture tests filter and selection; pending QA.
