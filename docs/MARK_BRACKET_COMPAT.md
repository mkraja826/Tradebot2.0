# Mark-triggered bracket request compatibility
Before new bracket POST, fetch the same product's demo ticker and validate mark against requested stop and target, using the documented mark_price trigger method. Require matching symbol/product and timestamp at most 30 seconds old. Crossed/unverified triggers are recorded as preparation_failed (no order POST); preserve model-selected levels rather than silently reprice. Record successful mark evidence in receipt. This is an API payload compatibility check, not a confidence, balance, or loss policy. Price can still move after validation; active legs must be separately observed. Does not manage or repair existing positions. Public ticker schema verified on both demo products; no exchange mutation in tests. https://docs.delta.exchange/
