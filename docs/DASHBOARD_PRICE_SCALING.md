# Display-only price scaling
Gold defaults to Body focus; BTC defaults to Full range. Users can change each symbol's mode during the session. Native autoscale provider uses visible candle open/close range plus padding, retaining actual high/low values and excluding upper indicator series from body-fit autoscale. Wicks, live quotes, position levels, and price overlays may extend outside the focused view. The note counts visible candles outside the unrendered body-fit bounds (not an exact rendered clipping count; scale margins and manual zoom can differ), and visible >2% high-low candles. Full range restores normal native candle and upper indicator autoscaling. Native log axis and reset auto-scale are available. No data filtering, wick truncation, journal writes, decision or order changes. Raw OHLC and indicator calculations remain unchanged. Daily extremes or abnormal candle bodies can still affect body fit. Browser fixture includes an extreme Gold wick; validates controls and no browser errors. QA pending.
