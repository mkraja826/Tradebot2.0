# Read-only MCP telemetry adapter
Stage separately from trading; do not switch trading release or restart recover-demo.
The adapter reads market-specific status.json and orders.sqlite with SQLite mode=ro/query_only. No AI requests, broker calls, credentials, raw prompts, or arbitrary context. It reports configured models with heartbeat freshness, bounded proposals, actual journaled attempts and verification, latency and token usage. Historical proposals retain original model IDs. Missing/stale evidence is explicit. Integrate into existing authenticated Recover MCP backend only after inspecting the deployed source and preserving its current four tool contracts. If the backend user lacks read access, use an existing authorized read-only interface rather than granting access to credentials or making journals public. No backend deployment or plugin tool registration is claimed by this commit.
