# Position lifecycle simulation
Pure offline abstract state transitions: flat/open, maintain, update bracket, partial/full close, uncertain acknowledgment, terminal fill reconciliation, unexpected changes. No broker or provider calls; no order request construction. Existing worker unchanged. Dashboard observes existing lifecycle snapshots with a 180-second freshness label and compares two reduce-only bracket leg quantities and direction against position size. This is not a protection guarantee. Historical unresolved orders remain visible. Live integration requires verified exchange semantics and explicit management action design; simulated transitions do not establish API compatibility.
