# Independent liquidation research
Bybit public mainnet BTCUSDT linear allLiquidation stream, read-only and unauthenticated; not Delta demo order data. Position side Buy means long liquidated, Sell short liquidated. Executed size and bankruptcy price archived without pretending price is actual fill. Record subscription/heartbeat and reconnect periods. Exact batch duplicates counted, identical rows within a batch retained; no event IDs or sequence, so completeness and unique event counts cannot be guaranteed. Empty observations are unknown, not proof of zero liquidations. No strategy activation, thresholds, AI requests, or exchange orders. Requires Debian python3-websockets 15.x. Run python -m recover_trading.liquidation_research --database PATH, --report for read-only inspection. Source: https://bybit-exchange.github.io/docs/v5/websocket/public/all-liquidation and https://bybit-exchange.github.io/docs/v5/ws/connect .
