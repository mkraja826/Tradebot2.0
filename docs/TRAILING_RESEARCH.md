# Trailing and cost-offset research
Five hypotheses share the same original Engine 2.0 reference replay
entry windows, 15-minute ATR measured at decision time, initial one-ATR
stop and three-ATR target. Compare a static bracket, cost-offset stop,
one-ATR trail, two-ATR trail and combined cost-offset/trail. Updates use
only fully completed surviving bars and become effective at the next
bar; no same-bar retroactive stop adjustment. Stop gaps use actual open
in the simulation. Cost-offset is not guaranteed net breakeven. Report
both same-bar ambiguity assumptions and select development outcomes only.
The already-inspected holdout is descriptive. No new entries, order
access, AI calls, execution policy changes or profitability claims.
