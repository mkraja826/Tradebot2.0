# Trade detail inspector
Read-only Trade history workspace. Select the latest 50 reconciled closed position episodes for the selected market. Shows gross, commissions and net before funding; reported funding is unverified. Exact decision-ID joins only; missing model plan or reason stays unavailable. Unique recent boundary fill timestamp, side, settlement currency and position state are required for first/last price display; not a weighted exit average. Filters on the order/fill journal do not change reconciliation. Selection persists across refreshes and resets on symbol changes. No API, execution, account or AI provider changes.
