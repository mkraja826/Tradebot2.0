# P1 Gold entry evidence research
Run the read-only report using a staged checkout: `python3 -m recover_trading.gold_entry_intelligence`.
Builds a decision-time Gold opportunity card from existing archived market context, deduplicated strategy families, contrary evidence, regime bias, archived executable quote, and distances from existing structure. Future-dated signal/candle records are excluded. Cost scenarios at 5/15/30 bps are illustrative research assumptions, not live costs, gates or recommendations. Actual outcomes are joined only in offline cohorts, never in the entry evidence card. No changes to prompts, strategies, direction consensus, service, leverage or risk policy. Verify actual journal coverage, quote timestamp conventions, and cohort sample sizes before considering any opt-in live integration. No automated policy promotion.
