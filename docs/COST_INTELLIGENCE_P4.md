# P4 cost intelligence
Read-only research CLI: python3 -m recover_trading.cost_intelligence --symbol BTCUSD --start <UTC epoch seconds> --end <UTC epoch seconds>.
Use XAUTUSD for Gold. The interval is half-open. Reconciled closed-trade commission accounting is separate from AI reservation-time usage. Failed calls with usage are included; unknown usage is not zero. Optional --rates-json supplies a caller-verified scenario schedule per model: {"model":{"currency":"USD","input_per_million":"1","output_per_million":"5"}} (example only, not real rates). Actual invoice costs, funding sign/completeness, and combined after-all-costs P&L remain unverified. No duplicate spread or slippage deduction from realized fills. No changes to live prompts, settings, order execution or services. Validate with VM journals and actual provider billing before any integration.
