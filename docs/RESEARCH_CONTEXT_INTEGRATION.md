# Opt-in research context
Default behaviour is unchanged. The staged service accepts --research-context together with --learning-journal (the existing observation-only journal). It attaches at most twelve reconciled prior episodes, gross/net fees, descriptive retention counts, current strategy family agreement, quote spread and linear per-contract exposure estimates, or current management geometry. Missing evidence is not a trading signal. Historical 10/25/1000 bps categories are research labels only. No additional model calls, strategy weights, execution changes, fixed allocation or forced exits. Added context is journaled before the original provider request; existing compacting and proposal validation remain. The historical scan performs a bounded read-only query, and may add latency; measure before activation. The archived comparison command (no provider calls) is python3 -m recover_trading.research_context --data-dir /var/lib/recover-mcp-snapshots/demo --learning-journal /var/lib/recover-mcp-snapshots/outcome-learning/learning.sqlite --symbol BTCUSD (or XAUTUSD). This compares context only, not candidate decisions or returns. No live deployment, prospective comparison or profitability claim. Enable only after reviewing real archived comparison and separate demo release approval.
