# Display-only candle freshness
The trading scanner remains unchanged. A separate public demo collector fetches up to 350 completed bars per market/timeframe; it retries missing latest bars at most every 30 seconds, uses two concurrent requests, preserves valid gaps and raw OHLC, and atomically writes JSON snapshots outside trading journals. No authenticated requests. The dashboard opts in with --chart-cache-dir /var/lib/recover-chart-feed. It uses an entire cache window if at least as recent as the trading archive; never splices feeds. Cache identity, boundaries, OHLC and source are validated before use. Fallback to archive is explicit, and stale data remains labeled. Configure the independent collector unit WorkingDirectory to the staged dashboard release (or a separately maintained symlink); enable only after QA. Do not point its writable cache at the trading journals. No guarantee of upstream availability. Browser locale explicitly en-US to address previous Lightweight Charts locale exception. Browser QA and live cache verification pending.
