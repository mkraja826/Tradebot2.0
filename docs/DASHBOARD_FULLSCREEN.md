# Immersive chart workspace
Fullscreen is a viewport-filling in-page modal, not a browser/OS fullscreen request. Same native chart, no duplicated chart instance. Compact sticky header, independent BTC/Gold market selector routed through existing dashboard market selection, optional price tools, collapsible indicators and executions, responsive chart sizing, touch controls, landscape layout, Escape/close and focus return; background interaction disabled using inert and body scroll lock. Existing raw candle, quote, study and execution APIs unchanged. Fullscreen smoke tests cover market switching, viewport geometry, focus restore and return to dashboard navigation. Actual handset UX/QA and deploy still pending.
