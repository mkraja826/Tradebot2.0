# Automatic missing-bracket restoration v1
Demo-only worker integration. Only an existing position with no active orders in complete snapshots can be considered. Require latest single entry fill from flat with matching acknowledged receipt, client ID, side, product, size and fill price. Require original AI triggers to straddle actual entry and a fresh exchange mark and be tick-aligned. No automatic price selection, new entry, amendment, cancellation or duplicate retry. Durable per-entry attempt before POST; verify subsequent observed legs and trigger source. Unknown outcomes stay recorded; subsequent observations are authoritative, no repeat POST. No added provider calls. Existing entry workflow unchanged. Limitations: partial/multiple entry fills, unavailable history, incompatible prices, manual/unattributed positions and existing mismatched orders require separate management. Fresh snapshots are not atomic with POST; exchange races remain possible. Existing position-level bracket creation was demonstrated manually on BTC demo, not through this new automatic branch.
