# Position management compatibility\nDelta India API documentation https://docs.delta.exchange/ (Place Order, Place Bracket order, Edit Bracket order, EditBracketOrderRequest), reviewed 2026-11-25. Reduce-only orders can reduce/close positions; bracket creation is position-level and one per open position. Edit bracket requires order ID and documents success-only acknowledgment; target identity for filled entry's position bracket, atomic update behavior, residual leg quantity after partial close, and sibling cleanup after full close remain unverified on demo. Fixture-only response and fill/position reconciliation tests; no request construction, broker mutation, or execution integration. Existing broker parser expects result, so success-only amendment cannot be treated as a normal order receipt. Historical reduction counts are descriptive and not attribution to reduce-only orders.\n
