# Management shadow v1
Live service captures one current position/market packet per market per five-minute observation bucket. Includes exact observed quantity, entry, mark, matching bracket evidence, product tick, market signals and consensus. Separate management prompt/schema supports maintain, repair_bracket, update_bracket, reduce, close; never opens/increases/reverses positions. Optional explicit evaluate method reserves one provider call in durable journal; service does not invoke it. Fixture-only evaluation tests, no extra recurring AI calls, no order mutation, no changes to actual entry or repair execution. Snapshot and scan are non-atomic, proposals remain advisory; validated triggers may expire. Dashboard API exposes preparation/evaluation status. Five-minute sampling is a research cadence, not an execution restriction.
