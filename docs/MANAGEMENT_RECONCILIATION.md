# Management reconciliation and provider diagnostics
Recurring management records safe provider error codes and telemetry, not response bodies. Enabled workers report waiting, evaluated or failed instead of falsely showing disabled between samples. The executor re-observes up to three unresolved management attempts per cycle, using only read requests and existing fill/order/position verification. It never resubmits an ambiguous mutation, and requires same observed creation timestamp and entry for remaining open positions. Unverified attempts remain unresolved. Reconciliation can establish a matching state, not unique causal attribution for bracket requests. Existing entry/repair rules and five-minute AI cadence remain unchanged. The two earlier generic provider errors cannot be retrospectively diagnosed from the journal.
