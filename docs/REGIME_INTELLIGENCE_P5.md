# P5 market-regime intelligence
Run from a staged checkout: python3 -m recover_trading.regime_intelligence --symbol XAUTUSD --split <UTC epoch seconds> --end <UTC epoch seconds> (or BTCUSD).
Uses existing signal-time regime and directional mark observations; no replacement classifier. Separates development and later holdout windows, purges overlapping boundary windows, selects nonoverlap before outcome filtering, checks return arithmetic, and reports 5/15/30 bps cost sensitivity. The cutoffs must be chosen without looking at holdout results for a genuine prospective test. Current output is descriptive, not causal or proof of out-of-sample profitability. Large-return exclusions are diagnostic and explicitly counted. No regime weights or strategy policies are changed. Actual VM journal coverage and independent forward validation remain required.
