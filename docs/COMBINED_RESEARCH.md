# Combined entry/exit research
Five entry hypotheses crossed with eleven exit hypotheses (fixed time,
five dynamic ATR/structure brackets, five trailing/cost-offset variants).
Reuse identical original nonoverlapping Engine 2.0 reference replay
windows, causal ATR evidence and the same estimated cost. Exit evaluation
starts at the actual simulated entry, not before it. Compare both
same-bar ambiguity policies. Report participation, per-entry expectancy,
and per-opportunity return. Select exploratory candidates on development
only with at least 50 entries and separately rank the two objectives.
Already inspected holdout remains descriptive. No execution integration,
orders, live limits or AI requests. A new forward sample is necessary
before claiming an improvement generalizes.
