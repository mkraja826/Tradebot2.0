# Shadow trade planner evidence
Build a small research summary from the corrected reference replay and
development-only calibration. Record the actual summary build time and
exclude the summary from any earlier archived decision. The shadow packet
contains only current direction, active rules, regime, opportunity
diagnostics and available historical development statistics. It contains
no account balances, credentials or executable proposal. A dedicated
SQLite journal deduplicates by market, decision timestamp and version.
Shadow failures are isolated from the existing execution path. No extra
model request, no AI prompt modifications, no weight or order changes.
This is preparation for a future AI comparison, not a completed model
evaluation. Reference and demo prices are explicitly distinct.
