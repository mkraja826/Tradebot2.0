# TP-only amendment contract
Delta documents PUT /v2/orders with id/product_id/size/stop_price, and separately PUT /v2/orders/bracket for bracket parameters attached to an entry order: https://docs.delta.exchange/ . The candidate for an already-open position uses its observed TP leg ID, leaves the SL untouched and requires exact position/leg identity, matching reduce-only pending mark-trigger orders and tick-aligned target geometry. Offline planning accepts an explicitly supplied target only. Verification checks both leg IDs, unchanged SL, new TP, position identity and quantity; no HTTP success alone. No execution integration or automatic TP amendment; a simulated observation is not proof of broker compatibility. Dashboard shows current candidate readiness without sending requests. No exchange test mutation authorized in this step.
