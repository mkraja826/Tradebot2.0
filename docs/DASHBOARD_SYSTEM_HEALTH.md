# System health command centre
Independent BTCUSD and XAUTUSD observation cards plus selected-market diagnostics. Uses existing 180-second freshness window and labels future timestamps or absent data. Refresh failures explicitly label retained data. Snapshot error categories counted, not raw error content. Existing wallet/position availability, bracket evidence, unresolved submissions, cycle timing and recorded feed lag shown independently. Historical entry and management latency are not live provider probes. No synthetic uptime, readiness claim, new API requests, model requests, execution gates or changes to trading workers. Existing diagnostic tables retained. Browser and full regression checks remain separate.
