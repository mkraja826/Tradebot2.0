# Gold reference chart
Public production Delta candles and ticker collected in separate display-only service, separate cache and explicit source. Gold defaults to reference on a linear full-range axis; BTC defaults to demo. Source selector is inside sticky header. No demo fill, mark, SL, TP or position level is projected onto reference candles. Reference unavailable is explicit, no fallback to demo. Demo view remains raw and unchanged, including anomalous bodies and wicks. No trading engine, AI or execution change. Reference cache path and unit need staging, verification and deployment. Production-market data may differ from demo prices; not a trade execution record.
