# Regime performance intelligence
Read-only report on archived signal-time regime and volatility, using existing 1h/4h EMA/ADX trend classification and 5m/15m ATR percentile volatility. Separate axes; high volatility may coexist with trending/mixed/ranging. Rule/family/horizon windows selected across all regime categories before outcomes, reserving horizon+300 seconds including missed windows. Family observations select one earliest signal when overlapping, not pooled independent trades or average strategy performance. Research returns use assumed 15 bps costs; actual attributed reconciled episodes separately joined to decision-time context, no funding. No rankings or statistical proof, no changes to weights, model calls or execution. Missing regimes remain unobserved.
