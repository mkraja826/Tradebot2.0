# Tradebot 3.0 source review

Demo research and offline tests snapshot; not an execution release. Runtime data, credentials, service configuration and private backups excluded. Three test files contain synthetic replacement literals.

## Known baseline limitations

The V3 rebuild does not contain four legacy healthcheck and off-host alert runner/installer scripts referenced by two inherited test methods. The same failures occur in the unchanged private snapshot. This export is not a complete deployment package. Do not interpret syntax verification or source synchronization as order authorization.
